# ScratchVideoPlayer
Generates video data from an MP4 file to be used in the Video Player scratch project found [here](https://scratch.mit.edu/projects/1168568721/). 
Use Turbowarp for best results: [here](turbowarp.org/1168568721/)

After the text file is generated, right click the frames list in the project and import the text. No further action is needed.
